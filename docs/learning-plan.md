# 학습 강화 설계안 — "알아야 할 내용이 곧 이기는 방법"

작성: 2026-11-14 · 근거 자료: `docs/battle-research.md` (국사편찬위원회·한국학중앙연구원)

## 1. 지금의 문제
1. 가장 오래 머무는 **전투 시간에 배우는 것이 거의 없다.** 역사와 이어진 규칙은 조총·수군 시너지·식량/땔감 정도.
2. 퀴즈가 **방금 읽은 문장을 바로 묻는다** → 떠올리기가 아니라 베끼기.
3. 맞혀도 군량 +2, 틀려도 그만 → **지식이 게임에 쓸모가 없다.** 틀린 문제가 다시 나오지 않는다.
4. 이야기는 「다음」 연타로 넘어가고, 어려운 낱말(유역·소굴·포위·임금과 신하의 관계)에 풀이가 없다.
5. 세 사건을 **이어 보고 비교하는 활동이 없다.**

## 2. 설계 원칙
- **교과서 핵심 개념 = 전투 규칙**: 학익진, 의병의 지리, 판옥선의 총통, 남한산성의 추위와 배고픔을 "써야 이기게" 만든다.
- **전투 전에 떠올리고, 전투로 확인하고, 전투 뒤에 까닭을 잇는다**:
  이야기(상황) → 작전 회의(떠올리기·판단) → 전투(역사 규칙) → 결과(왜 이겼나/졌나) → 기록(지도·도감·흐름 띠).
- **글은 짧게, 경험은 크게**: 이야기 한 번에 2~3줄. 나머지는 규칙과 화면으로 보여 준다.
- **정확성**: 퀴즈 정답과 이야기 문장은 교과서 문장만 쓴다. 교과서보다 자세한 내용은 📜「더 알아보기」 표시를 달고 퀴즈로 내지 않는다.
- **새 그림 없이**: 지형(숲·논·암초·성벽)은 칸 색과 무늬(CSS), 기존 도트 그림으로 만든다.

## 3. 게임 전체에 들어가는 장치

### ① 작전 회의 (퀴즈 자리 옮기기)
- 전투 **전에** 한두 문제. **앞 단계·앞 장 내용**을 묻는다(시간을 두고 떠올리기 → 오래 기억).
- 맞히면 **이번 전투에 도움**: 예) 필살기 마나를 채우고 시작, 지형 정보 공개, 적 한 명 줄이기.
- 틀리면 풀이를 보여 주고, **다음 작전 회의에 다시 나온다**(오답 다시 풀기).
- 문제 형식: 고르기 / 지도에서 누르기 / 순서 맞추기 / 인물–한 일 짝짓기 / 원인→결과 잇기 / 그림(진 모양) 고르기.

### ② 역사 규칙 (전투)
- 판 위에 **지형 칸**: 바다·섬, 강, 숲, 논, 좁은 물길(암초), 성벽.
- 단계마다 그 역사에 맞는 규칙 1~2개(아래 4장). 처음 나올 때 한 줄 안내 + 📜 더 알아보기.

### ③ 역사 한마디 (전투 중 말풍선)
- 적·군사가 **처음 등장할 때**, **필살기를 쓸 때**, 역사 규칙이 **처음 발동할 때** 한 줄.
  예) "학익진! 학이 날개를 펴듯 적을 둘러쌌어요" / "의병은 숲에 숨어 있다가 공격해요"
- 이미 있는 군사 설명(fact)을 그대로 쓴다. 한 판에 3~4번 이하로.

### ④ 낱말 풀이
- 이야기 속 어려운 낱말에 밑줄 → 누르면 쉬운 뜻. 처음 한 번은 반짝임.
- 후보: 왜구, 소굴, 노략질, 유역, 여진, 4군·6진, 조총, 수군, 판옥선, 의병, 명, 포로, 국가유산, 청, 임금과 신하의 관계, 피신, 포위, 항복.

### ⑤ 기록: 지도 · 역사 도감 · 흐름 띠
- **지도**(1장에 이미 있음): 2·3장에도 부산 상륙 → 한산도 → 평양성 / 압록강 → 남한산성 표시.
- **역사 도감**: 만난 인물·무기·사건 카드(기존 도트 그림 + 교과서 한 줄 + 📜 더 알아보기).
- **흐름 띠**: 장과 장 사이에 "세종 때 → (약 200년 뒤) 임진왜란 → 병자호란". 지금 어디쯤인지 표시.

### ⑥ 마무리 활동
- 각 장 끝: 지금의 빈칸 채우기(교과서 정리) + **원인→과정→결과 카드 순서 맞추기**.
- 마지막(3장 뒤): **세 사건 비교표** — 누가 쳐들어왔나 / 어떻게 맞섰나 / 결과는.

### ⑦ 선생님용 학습 기록 (이름 저장 없음)
- 장 끝 화면에 맞힌 문제 수, 다시 틀린 문제, 3장 회의에서 고른 의견과 그 까닭(한 줄 쓰기).
- 교실을 돌며 확인하거나, 회의 결과로 토론 수업을 이어 갈 수 있게.

## 4. 단계별 설계

### 1장. 세종 — 쓰시마섬, 4군 6진
| 단계 | 이야기(교과서) | 작전 회의 | 역사 규칙 | 결과·기록 |
|---|---|---|---|---|
| 1-1 쓰시마 | 왜구가 바닷가 마을을 노략질, 소굴은 쓰시마섬 | (첫 단계: 조작 연습) | **상륙**: 바다 칸은 병선만, 섬 칸에 올라야 두목을 칠 수 있음. **매복**: 섬 숲에서 왜구가 튀어나옴 📜"조선군도 매복에 걸려 피해를 입었어요" | 지도에 "항복!" 깃발. 도감: 이종무·병선 |
| 1-2 압록강 | 압록강 근처 여진을 몰아내라 | "1-1에서 공격한 왜구의 소굴은?" (맞히면 마나) | **강 칸**: 건너는 데 한 차례. 여진 기병은 빠름(이미) | **진 세우기**: 이긴 칸에 진 → 다음 단계에서 그 칸 군사 튼튼. 4군 깃발. 도감: 최윤덕 |
| 1-3 두만강 | 두만강 근처 여진도 몰아내라 | **지도 누르기** "4군을 설치한 곳은?" | 1-2의 진이 남아 있음. 📜"김종서는 10여 년에 걸쳐 6진을 만들었어요" | 6진 깃발 → 📜"남쪽 사람들이 옮겨 와 살았어요" → 다음 장 군량 +1 |
| 장 끝 | 세종 때 쓰시마 항복, 4군 6진으로 영토 확장 | — | — | 빈칸 정리 + "사압육두" 지도 퀴즈 |

### 2장. 임진왜란
| 단계 | 이야기(교과서) | 작전 회의 | 역사 규칙 | 결과·기록 |
|---|---|---|---|---|
| 2-1 침략 | 조총을 갖춘 일본군의 침략, 잇단 패배 | 📜 **고개에 숨을까, 들판에서 싸울까?** (정답 없음, 결과가 다름) | 들판 → **논 칸**(기병 1칸만). 조총병은 멀리서 강함. 지는 장면(교과서 흐름) | **"왜 졌을까?"** 고르기 → 정답: 조총(교과서). 📜 준비·군사 수·지형도 까닭이었어요 |
| 2-2 수군 | 바다에서 이순신이 이끄는 수군이 활약 | **진 모양 그림 고르기** "학익진은?" → 맞히면 이순신 필살기 준비 | **학익진**: 적 하나를 3명이 둘러싸면 공격력↑(이순신이 있으면 더). **판옥선**: 멀리서 쏨, 붙는 공격에 강함. **좁은 물길**: 판옥선 1칸만 → 미끼로 넓은 바다로 꾀어내기 | 지도: 한산도. 도감: 이순신·판옥선·거북선 |
| 2-3 의병 | 백성이 스스로 군대를 만들어 일어남(의병) | "나라를 지키려고 스스로 일어난 백성의 군대는?" (2-2 내용도 섞어서) | **숲 칸**: 의병은 숨고, 숲에서 치는 첫 공격이 셈. **가짜 군사**(의병장 필살기). **길목 지키기**: 적이 아래쪽 끝(전라도 가는 길)에 닿지 못하게 | 도감: 의병·곽재우(📜) |
| 2-4 명군 | 명군이 도우러 옴 → 위기 극복 | **짝짓기** 수군–이순신 / 의병–백성 / 명–도우러 온 나라 | **성 되찾기**: 성벽 칸은 명 포병만 부숨. 「위기 극복」 시너지(이미) | 지도: 평양성 |
| 장 끝 | 피해(이미 있음) | — | — | 빈칸 정리 + **원인→과정→결과 순서 맞추기** |

### 3장. 병자호란 — 남한산성
| 날 | 성 밖 소식(📜) | 작전 회의 | 역사 규칙 |
|---|---|---|---|
| 1일 | 청이 임금과 신하의 관계를 요구 → 거부 → 침략(교과서). 청 기병이 산성을 지나쳐 곧장 서울로 | "인조가 피신한 곳은?" | **청 기병 우회**: 우리 군사를 지나쳐 성으로 곧장 달림 → 길목을 막아야 함 |
| 2일 | 근왕병이 오고 있대요! 포 소리와 횃불이 보여요 | 2장 복습 문제 | 식량·땔감 감소(이미): 배고프면 공격력↓, 추우면 체력↓ |
| 3일 | (회의 — 이미 있음) 근왕병이 이겼지만 화약이 떨어져 오지 못했대요 | 싸우자 / 항복하자 + **까닭 한 줄 쓰기** | |
| 4일 | 청군이 큰 대포로 성을 쏘아요 | 1장 복습 문제 | 성이 깎인 채 시작 |
| 5일 | 강화도가 함락됐대요 | — | |
| 끝 | **교과서 문장**: 추위와 배고픔 등으로 어려워지자 결국 인조는 청에 항복 | 결과 카드(이미) | 세 사건 비교표 |

- 식량 막대 옆에 📜"성안 식량은 50일분이었어요"(원문 확인 후).

## 5. 만드는 순서(제안)
1. **1차**: 작전 회의(①, 오답 다시) + 역사 한마디(③) + 학익진·판옥선(2-2) + 의병 숲(2-3) + 청 기병 우회·성 밖 소식(3장)
2. **2차**: 지형 칸 전체(상륙·강·논·좁은 물길·성벽) + 진 세우기 + 2-1 작전 선택 + 2-4 성 되찾기
3. **3차**: 낱말 풀이(④) + 도감·흐름 띠(⑤) + 마무리 활동(⑥) + 선생님 기록(⑦)

- 규칙을 더할 때마다 `tools/sim.js`로 난이도를 다시 맞춘다.
- 새 그림·소리 없이 가능(지형은 칸 색·무늬). 더 예쁜 지형 그림이 필요하면 PC 도구(Pixelbolt)로 따로.
